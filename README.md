## Déploiement

**Vercel (recommandé)** — connectez ce dépôt GitHub sur https://vercel.com/new,
ou en ligne de commande :

```bash
npm i -g vercel
vercel --prod
```

Site 100 % statique : aucun build, aucune dépendance. Polices Google (Cormorant Garamond,
Montserrat) chargées via CDN.
